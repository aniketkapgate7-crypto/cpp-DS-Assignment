# Data Structures Lab Assignments

C++ programs for the Data Structures course (Sem I, FY 2026–27, School of AI, MIT ADT University).

## Assignments

1. **Smart Library** – arrays, searching, sorting
2. **Student Performance** – roll no search, merit sorting
3. **Smart Restaurant** – queue, stack, recursion
4. **Bank Token System** – token queue + served history stack
5. **Restaurant Order Management** – queue, priority queue, stack, recursion
6. **Bank Token System** – queue, priority queue, stack
7. **Hospital Patient System** – linked list + hash table
8. **E-Commerce Inventory** – linked list + hash table
9. **University Enrollment** – nested linked lists + hash table
